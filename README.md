# NicolasKheirallah's Homebrew Tap

## How do I install these casks?

```bash
brew tap nicolaskheirallah/tap
brew install --cask hisingen
```

Or in one command:

```bash
brew install --cask nicolaskheirallah/tap/hisingen
```

## Casks

| Cask       | Description                                    |
| ---------- | ---------------------------------------------- |
| `hisingen` | Polestar and Volvo vehicles in the macOS menu bar |

The `hisingen` cask is updated automatically by CI on every
[Hisingen release](https://github.com/NicolasKheirallah/Hisingen/releases).
